## 设计取舍

- **系统通知**：绿色版无包身份，Windows Toast 需要 AUMID + COM 激活器，因此新邮件提醒走原生托盘气泡而非 Windows 通知中心。
- **加密凭据**：主密钥保存在用户设备，仓库不分发任何密钥；开发者需自行配置测试账号。
- **双线并存**：Tauri 与 C# 线共用核心但各自独立演进，不做相互替代。
